# 👻 Ghostforge voice-test.eu

**Open Source TTS-Vergleichsplattform. Alle Stimmen. Alle Sprachen.**

Vergleiche synthetische Stimmen aller großen TTS-Anbieter und Open-Source-Modelle in 25 europäischen Sprachen. Eine Geisterschmiede für Audio-Auswahl.

🔗 **Live:** [voice-test.dev](https://voice-test.dev) (Cloudflare Pages, statisch)

---

## Was ist das?

voice-test.eu ist eine statische Vergleichsplattform für Text-to-Speech-Stimmen. Sie zeigt Audio-Samples von:

- **Enterprise-Provider:** OpenAI TTS, Microsoft Azure, Microsoft Edge TTS, ElevenLabs
- **Open-Source-Modelle:** Piper (rhasspy), und wachsend (XTTS, Kokoro, Bark — geplant)

…in 25 europäischen Sprachen (24 EU-Sprachen + Norwegisch) und 3 Text-Varianten:

- **v1_simple:** Neutral/Informational
- **v2_medium:** Fließtext mit Zahlen/Eigennamen
- **v3_emotional:** Begeisterung/Ausrufe

## Features

- 🔊 **Single-Player** mit Toggle (Play/Pause)
- ⚖️ **A/B-Vergleich:** zwei beliebige Stimmen direkt vergleichen, mit sequentiellem Playback
- 🌍 **Filter:** Sprache, Provider, Geschlecht, Lizenz (OSS/proprietär), Sortierung
- 🔍 **Volltext-Suche** nach Voice-Namen
- 📱 **Mobile-first**, Vanilla HTML/CSS/JS (keine Libraries, schnelle Ladezeit)
- 🤖 **Auto-Ticker:** GitHub Action entdeckt wöchentlich neue HF-Modelle

## Mitmachen

### Eigenes Modell hinzufügen

1. **Sample generieren:** Nutze `scripts/s2_generate.py` (Enterprise) oder `scripts/s3_vm_generate.py` (OSS auf GPU-VM).
2. **models.json erweitern:** Beschreibung, Lizenz, Sprachen eintragen.
3. **PR stellen.** Bot übernimmt den Build.

Siehe auch `METHODOLOGY.md` für die genaue Generierung.
